\# Smart Bus Attendance System



Projet de Fin d'Études (PFE)



Système embarqué intelligent installé dans les bus industriels pour :

\- Gestion automatisée de présence des employés

\- Reconnaissance faciale

\- Suivi GPS

\- Mesure de température

\- Transmission des données vers une plateforme de supervision
